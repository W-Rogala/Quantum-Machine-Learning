## Aktualizacja istniejącego GitHuba

Katalog roboczy nie jest rozpoznawany jako repozytorium Git. Brakuje działającej
historii i adresu zdalnego repozytorium, więc nie wykonano commit ani push.
Przygotowano `output/release/QML-github-ready-2026-10-09.zip` i manifest SHA-256.
Nie zastępuj metadanych `.git` istniejącego repozytorium zawartością tej paczki.

1. W działającej kopii repozytorium utwórz gałąź aktualizacji.
2. Rozpakuj paczkę jako nakładkę plików do katalogu tej kopii. Paczka nie zawiera
   `.git`. Nie usuwaj automatycznie plików występujących tylko w repozytorium.
3. Obejrzyj `git status --short` i `git diff --stat`, następnie treść zmian.
4. Uruchom testy i kontrole opisane w README oraz README monografii.
5. Wybierz pliki do commit, zapisz commit i wyślij gałąź do przeglądu zmian.

Samodzielny HTML i ZIP raportu przeznaczone są na osobne assety wydania;
nie dodawaj środowisk, pełnych archiwów ani danych kont. Nie nadano nowej
licencji własnego kodu; aktualny status jest w LICENSE_STATUS.md.
