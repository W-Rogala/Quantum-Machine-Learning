# Lokalne wyniki historyczne

Ten katalog przechowuje oryginalne artefakty i wyniki. Nie jest publikowany w całości.
Kod eksperymentów przeniesiono do `experiments/legacy/`; pozostawione pliki `.py`
są adapterami zachowującymi stare importy i polecenia. Obliczenia nadal zapisują
wyniki w tym katalogu. Do nowego uruchomienia wybierz nową nazwę wyników lub katalog.

Małe zestawienia do przeglądu są w `results/`. Manifest oryginalnego zasobu:
`docs/audit/inventory.csv`. Nie usunięto historycznych CSV, NPZ, JSON ani raportów.
